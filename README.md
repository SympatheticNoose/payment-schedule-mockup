# График платежей — макет

Интерактивный макет редактора графика платежей для обсуждения интерфейса.

[Открыть макет](https://sympatheticnoose.github.io/payment-schedule-mockup/)

Можно создавать несколько этапов сразу, менять аванс и два вида удержаний,
редактировать суммы и сроки, смотреть итоговые выплаты.

Это демонстрация интерфейса. Финансовое дисконтирование не реализовано.
Кнопка «Сохранить график» сохраняет изменения только в памяти открытой страницы.
Обновление страницы возвращает исходный пример. Данные посетителей не отправляются на сервер.

Для работы без интернета скачайте файлы и откройте index.html в браузере.
Все стили, скрипты и иконки встроены в HTML; установка зависимостей не требуется.

Иконки: Lucide 1.17.0. Условия сторонних лицензий находятся в файле ЛИЦЕНЗИИ.txt.
